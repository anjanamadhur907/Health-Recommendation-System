[QUICK START COMMANDS]
--------------------------------------------------------------------
1. Setup Backend:
   cd Backend
   npm install
   node seed.js    # Seed initial disease and symptom data into PostgreSQL
   node app.js     # Start backend server on port 3000

2. Setup Frontend:
   cd Frontend
   npm install
   npm run dev     # Start Vite dev server on port 5173
