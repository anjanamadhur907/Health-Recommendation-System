# 🩺 Health Recommendation System (Full-Stack)

A full-stack Health Recommendation System built using Node.js, Express, Sequelize, MySQL, and React. It analyzes user symptoms to suggest possible diseases along with precautions, home remedies, and Ayurvedic recommendations.

## 🚀 Features
- User authentication (signup/login with phone number)
- Symptom-based disease suggestions
- Precautions and home remedies
- Ayurvedic recommendations
- Responsive frontend UI
- RESTful API integration

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MySQL
- ORM: Sequelize

## ⚙️ Setup

### Backend
cd backend  
npm install  
npm start  

### Frontend
cd frontend  
npm install  
npm run dev
